# em_motion

`em_motion` 是运动模型与轨迹规划库，定位为“纯算法层”。

- 不直接操作硬件外设。
- 硬件控制能力通过函数指针接口注入。
- 同时覆盖底盘运动（小车）和云台运动（PTZ）。

## 3. 关键算法约束

### 3.1 差速运动学

- 正解：`v = (vr + vl) / 2`，`w = (vr - vl) / L`
- 逆解：`vr = v + w * L / 2`，`vl = v - w * L / 2`
- 里程计积分：
  - `x += v * dt * cos(theta)`
  - `y += v * dt * sin(theta)`
  - `theta += w * dt`

### 3.2 阿克曼运动学

- 自行车模型：`tan(delta) = L / R`
- 逆解：`R = v / w`，`delta = atan(L / R)`

### 3.3 梯形规划

- 三段：加速段、匀速段、减速段
- 当位移不足以达到最大速度时，退化为三角速度曲线

### 3.4 S 曲线规划

- 七段：加加速、匀加速、减加速、匀速、加减速、匀减速、减减速
- 需要满足位移、速度、加速度、加加速度联立约束

### 3.5 倒立摆控制

- 常用控制形式：`tau = Kp * (target - angle) - Kd * ang_vel + gravity_comp`
- 重力补偿常用项：`m * g * l * sin(angle)`

## 4. 设计原则

### 4.1 算法层与驱动层解耦

- `em_motion` 只提供目标状态（角度/速度/加速度/力矩）
- 真正的 PWM/UART/FOC 输出在外部驱动模块实现

### 4.2 PTZ 三层结构

1. 规划层：`model_trajectory`
2. 抽象层：`ptz_interface`
3. 实现层：`pwm_ptz`（后续可扩展 `drv_servo_bus`、`drv_stepper`）

### 4.3 单位与接口一致性

- 角度：弧度 `rad`
- 角速度：`rad/s`
- 线速度：`m/s`
- 时间：`s`

## 5. 测试建议

每个模块至少提供纯 C 的最小测试，覆盖：

- 基本输入输出正确性
- 边界值（零速度、零位移、极小时间步长）
- 约束不越界（速度/加速度上限）
