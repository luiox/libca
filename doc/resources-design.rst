.. _resources-design:

资源嵌入设计
============

resources 在构建期把目录树编入消费 target，运行时从只读内存访问资源。这样可以把小文件和程序作为单个二进制分发，无需约定运行目录或在启动时枚举文件。

.. _resources-design-build-rule:

清单到生成头
------------

xmake rule ``libca.resources.embed`` 读取 UTF-8 的 ``.resources`` 清单，每行以挂载名关联一个目录，相对目录以清单所在目录为基准。规则拒绝同一清单中的重复挂载名、无效挂载名和不存在的目录。每个挂载独立枚举文件，空目录不产生条目，空文件保留为零长度条目。路径统一使用前导斜杠和斜杠分隔，再按路径排序，使生成结果与目录遍历顺序无关。

生成头写入 target 的 autogen 目录，由构建规则加入 include 搜索路径。规则记录清单、挂载目录和枚举所得的文件依赖，内容变化才重写生成头。数据由 constexpr 字节数组持有，单文件上限为 1 MiB，以约束生成头体积和 C++ 编译开销。更大文件需要不同的嵌入方式。

.. _resources-design-bundle:

挂载隔离与读取
--------------

每个挂载生成一个只读 bundle，条目表引用静态字节数组。include 生成头触发挂载注册。不同挂载可含同名路径，查找先选择 bundle，再按区分大小写的路径查询。跨 target 同名挂载由首个成功注册的 bundle 生效，因此需要确定的查找结果时应为各挂载使用唯一名称。

有序路径表支持二分查找，目录前缀对应一段连续条目，迭代可直接返回该范围。查询返回对嵌入存储的借用视图，不复制文件字节。注册在启动阶段完成，之后可并发读取。
